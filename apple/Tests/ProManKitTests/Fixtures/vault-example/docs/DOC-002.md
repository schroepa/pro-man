# Architektur & Anti-AI-Slop Richtlinie

## Design-Prinzipien
1. **Zero-Borders**: Trennungen erfolgen ausschließlich über tonale Hintergrundkontraste und diffuse Tiefenschatten.
2. **Obsidian-Style Storage**: Aufgaben liegen als editierbare .md-Dateien auf dem Dateisystem.
3. **Volle Tastatur- & Screenreader-Zugänglichkeit** (WCAG 2.1/2.2 AA).
