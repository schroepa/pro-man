## Was du brauchst

- **Chrome oder Edge** (empfohlen) — für den direkten Ordnerzugriff über die File System Access API
- Optional: einen leeren Ordner als Vault, z. B. `ProMan-Vault/`

Öffne die App unter [/app/](/app/index.html).

## Zwei Wege zum Start

Beim ersten Besuch siehst du einen Banner:

1. **Ordner verbinden** — wähle einen Ordner auf dem Gerät. ProMan speichert Tasks, Docs und Wissen als Markdown darin.
2. **Mit Beispieldaten starten** — sofort ausprobieren, ohne Ordner. Ein Demo-Hinweis in der Sidebar zeigt, dass du noch nicht „echt“ speicherst.

Du kannst später jederzeit einen Ordner verbinden und die Demo-Daten verwerfen.

## Das Dashboard

Nach dem Start landest du auf dem **Dashboard**: Fokus-KPIs, Aufmerksamkeit-Liste und schnelle Sprünge zu Board, Liste oder Favoriten.

Von dort aus:

- **Board** — Kanban mit Spalten und Drag-and-Drop
- **Liste** — tabellarisch filtern und sortieren
- Sidebar — Kunden, Docs, Wissen, Backoffice

## Erster Erfolg

1. Öffne eine Beispiel-Aufgabe oder lege eine neue an (⌘/Ctrl + N bzw. über die Topbar).
2. Ändere Status oder Titel — speichern passiert lokal.
3. Wenn du bereit bist: Sidebar → **Ordner verbinden** und mit echten Daten weiterarbeiten.
