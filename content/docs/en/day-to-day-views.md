## Views at a glance

| View | When |
|---|---|
| **Dashboard** | Day start, focus and attention |
| **Board (Kanban)** | Status flow, WIP, drag-and-drop |
| **List** | Dense overview, filters, sorting |
| **Gantt** | Timelines, dependencies, milestones |
| **Calendar** | Due dates in a month view |
| **Docs / Knowledge** | Writing and lookup |
| **Backoffice** | Clients, projects, team & people |

Switch via the sidebar or the command palette.

## Filter and focus

The top bar filters by client, project, cycle, and more. The dashboard sends you into the list with matching filters via focus KPIs.

## Command palette (⌘K / Ctrl+K)

Fast entry for:

- Opening views
- Searching tasks and docs
- Running actions

Fuzzy search groups recents and hits. Arrow keys, Home/End, and Enter cover keyboard use.

## Shortcuts

Open the shortcuts dialog in the app (via the palette or help action) for the current list — including new task, search, and view switching.
