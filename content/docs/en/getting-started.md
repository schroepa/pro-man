## What you need

- **Chrome or Edge** (recommended) — for direct folder access via the File System Access API
- Optional: an empty folder as your vault, e.g. `ProMan-Vault/`

Open the app at [/app/](/app/index.html).

## Two ways to start

On first visit you’ll see a banner:

1. **Connect folder** — pick a folder on your device. ProMan stores tasks, docs, and knowledge as Markdown inside it.
2. **Start with sample data** — try immediately without a folder. A demo badge in the sidebar shows you’re not on “real” storage yet.

You can connect a folder later and clear the demo data.

## The dashboard

You land on the **dashboard**: focus KPIs, an attention list, and quick jumps to board, list, or favorites.

From there:

- **Board** — Kanban columns with drag-and-drop
- **List** — dense filtering and sorting
- Sidebar — clients, docs, knowledge, backoffice

## First success

1. Open a sample task or create a new one (⌘/Ctrl + N or via the top bar).
2. Change status or title — saves stay local.
3. When ready: sidebar → **Connect folder** and continue with real data.
