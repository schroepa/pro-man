# Pro-Man Brand Assets

UI-Subset des Logo-Pakets v1.1. Vollständige Varianten (PNG, Mono) liegen im Design-Export.

| Datei | Verwendung |
|---|---|
| `lockup-horizontal-{light,dark}.svg` | Primär: Sidebar |
| `mark-{light,dark}.svg` | Bildmarke allein |
| `wordmark-{light,dark}.svg` | Wortmarke allein |
| `lockup-stacked-{light,dark}.svg` | Gestapelter Lockup |
| `app-icon-{light,dark}.svg` | App-Icon-Vorlage |
| `avatar-{light,dark}.png` | Social Avatar 800 px |

Favicon/PWA/OG liegen im `public/`-Root (`favicon.svg`, `icon-*.png`, `og-image.png`).

**Regel:** `light` = dunkle Tinte auf hellem Grund; `dark` = helle Tinte auf dunklem Grund. Mindestbreite Lockup horizontal: 96 px.
